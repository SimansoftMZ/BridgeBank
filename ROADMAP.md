# Roadmap do BridgeBank

## Versão 1.0 (Atual) ✅

- [x] Motor de reconciliação básico
- [x] Estratégias de correspondência:
  - [x] Por referência exata
  - [x] Por valor e data
  - [x] Por descrição
- [x] Leitores de extractos Excel:
  - [x] BCI
  - [x] Millennium BIM
  - [x] Standard Bank
- [x] Geradores de ficheiros de pagamento:
  - [x] BCI (TXT)
  - [x] Millennium BIM (CSV)
  - [x] Standard Bank (XML)
- [x] Testes unitários
- [x] Documentação básica
- [x] Aplicação de exemplo

## Versão 1.1 (Próxima) 🚧

- [ ] Leitores de PDF
- [ ] Suporte para mais bancos moçambicanos:
  - [ ] Absa Bank
  - [ ] First National Bank
  - [ ] Banco Terra
- [ ] Melhorias nas estratégias:
  - [ ] Machine Learning para melhor correspondência
  - [ ] Histórico de reconciliações anteriores
- [ ] API REST para integração
- [ ] Interface gráfica web (opcional)

## Versão 1.2 (Futuro) 🔮

- [ ] Suporte para bancos internacionais
- [ ] Importação/Exportação em formatos OFX, QIF
- [ ] Relatórios de reconciliação
- [ ] Dashboard de análise
- [ ] Detecção automática de taxas e comissões
- [ ] Suporte para múltiplas moedas
- [ ] Integração com ERPs populares:
  - [ ] Primavera
  - [ ] SAP Business One
  - [ ] Sage

## Versão 2.0 (Visão de Longo Prazo) 🌟

- [ ] Reconciliação em tempo real
- [ ] Inteligência artificial para classificação automática
- [ ] Suporte para blockchain e criptomoedas
- [ ] Aplicação mobile
- [ ] Cloud hosting opcional
- [ ] Multi-tenancy
